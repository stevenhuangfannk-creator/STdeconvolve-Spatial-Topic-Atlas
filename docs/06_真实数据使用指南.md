# 真实数据使用指南 / Applying the workflow to new data

本章是将已复现模块迁移到新数据的设计说明。当前仓库使用公开 mOB 数据；本章没有运行用户 PI 数据，没有 PI–Healthy 结果。真实数据替换、科学筛选和正式结果命名须由研究者审查后执行。

## 1. 开始之前先明确问题

先写出一个可以被图和数据检验的问题，例如：“无参考模型能否分离出在炎症区域富集、具有成纤维细胞相关表达特征的 Topic？”随后定义哪些证据足以支持它，哪些候选解释也可能导致同样图形。不要先指定“必须得到某个新亚群”，再调 K 或筛 spots 追求预期结果。

记录平台、物种、患者/动物、切片、批次、条件、生物学重复数和每个 spot 的空间单位。STdeconvolve 可以在没有单细胞参考时拟合，但可靠命名仍需基因特征、组织形态、参考表达或其他证据。[官方适用范围](https://jef.works/STdeconvolve/)

## 2. 准备输入 / Input contract

| 输入 | 必需形式 | 核查内容 |
|---|---|---|
| counts | gene × spot 的非负整数稀疏矩阵 | gene/spot ID 唯一；无 NA/负值；保留原始 counts |
| coordinates | 每个 spot 一行，含 `x`、`y` | rownames 与 counts 列名对应；明确阵列单位还是 µm |
| metadata | 每个 spot 一行 | `sample_id`、`condition`、`patient_id`、`batch`；组织层/区域若有则另列 |
| reference（可选） | gene × 已注释类型的参考表达或有来源的 marker sets | 物种、基因ID、版本、技术来源与匹配程度 |
| tissue image（可选） | 原始 H&E/其他组织图及配准信息 | 图像原点、轴方向、缩放与坐标变换来源 |

R 中先检查输入，再决定过滤；下面只是检查示例，不会执行真实 QC 或更改注释。

```r
# x_counts: gene × spot；x_pos: spot × c("x", "y")
stopifnot(!anyDuplicated(rownames(x_counts)),
          !anyDuplicated(colnames(x_counts)),
          all(c("x", "y") %in% colnames(x_pos)),
          all(colnames(x_counts) %in% rownames(x_pos)),
          all(is.finite(x_counts)), all(x_counts >= 0),
          all(x_counts == floor(x_counts)))
x_pos <- x_pos[colnames(x_counts), c("x", "y"), drop = FALSE]
stopifnot(identical(colnames(x_counts), rownames(x_pos)))
```

对大型稀疏矩阵，完整有限值/整数检查可针对非零槽位分块完成；不要为检查而将整张大矩阵转成 dense。只有基因筛选后的小 corpus 才按官方要求转成 spot × gene。零总计数 spots 不能送入 LDA。

Seurat/SCE 等对象中要明确取 raw counts 层；不要用 `data`、`scale.data`、SCT residuals、integrated assay 或 embedding。原始整数 counts 不是“需要再归一化才能建模”的输入。图件可另用归一化表达，但须在图注中区分。[Getting Started](https://jef.works/STdeconvolve/getting_started.html)

## 3. 保护上游结果与资源 / Preserve inputs and resources

新数据建立独立目录/配置，输出写到新路径，先保存原始文件 checksum 与元信息；不要覆盖已确认的 Seurat 对象、UMAP 坐标、细胞注释或其他 Figure。优先使用用户已确认 QC 和注释，STdeconvolve 模块只做所需输入检查及明确记录的过滤。

16 GB Windows 机器默认 `ncores=1`。先在少量 K、筛选后的基因和有代表性的公开/小样本上估计时间与内存，再确定真实全数据范围。`as.matrix()` 会使稀疏矩阵稠密化；大规模合并前应估算 `spots × genes × 8 bytes` 的基础矩阵开销及模型/并行复制额外内存。当前日志的 R 堆内存不是整机 RSS，也不是所有子进程峰值。

包安装使用项目隔离库；先查 R/Bioconductor 与 STdeconvolve 版本，不自动升级、降级或修复用户全局环境。若预计超出资源或需要大改依赖，先报告具体冲突与可行选项。

## 4. 每一步的迁移方式与验收

| 阶段 | 调整和保留内容 | 验收标准 |
|---|---|---|
| 预处理 | `min.lib.size`、`min.reads`、`min.detected`、检出比例、OD `alpha/nTopOD` | 保存过滤前后规模、排除 ID、基因列表；不能按期待标签筛除 cells/spots |
| K 搜索 | 明确候选 K 与单核种子；逐步扩大合理范围 | perplexity、α、raw θ rare Topics 齐全；末端最低值时说明范围有限 |
| 提取 | 保存 raw θ、显示阈值 θ、概率 β 和缩放 β | row/column ID 对齐；θ 行和1；β概率行和1 |
| 注释 | markers、独立参考表达、空间层/形态证据分开 | 所有候选证据与未注释 Topics 保留；不强制命名 |
| 图件 | 统一比例/颜色、明确阈值与原始表达尺度 | PNG/PDF/SVG 可打开；完整图例；不截断坐标/组织 |
| 下游 | 富集背景、零假设、比较单位预先写清楚 | 全表/不显著结果、参数和限制可追溯 |

不同数据不应机械照搬 mOB 的 K=8 或论文的 K=12。低 perplexity 是拟合诊断；同一数据重复种子检验数值敏感性，跨独立样本才提供生物学稳健性信息。[官方 K 与失败示例](https://jef.works/STdeconvolve/failure_examples.html)

## 5. 多样本与条件比较

两条路线都需要先写清研究目标：

1. **分别拟合再匹配**：适合保留样本特异表达。比较 β 的共同基因相关/匹配，报告共享基因数和不匹配 Topics。Topic 1 不会因编号相同而在两样本中自动相同。
2. **联合拟合共同 Topic 空间**：同一样本多切片、存在共享表达成分时可考虑。按切片分别选 OD genes 再取并集，是官方讨论的策略；联合拟合不自动消除批次，也可能掩盖条件特异状态。

官方例子见 [Combining Datasets](https://jef.works/STdeconvolve/combining_datasets.html)。本项目若只做两个切片的平均 θ 柱图，应称“描述性比较”；不能把几百个 spots 当作几百个患者并进行疾病推断。患者/动物是生物学重复单位，切片与 spots 具有嵌套结构和空间相关。疾病效应、批次、解剖位置与测序深度需纳入独立统计设计。

## 6. STdeconvolve 在种植体周围炎中的潜在应用 / Future PI design

以下全为**未来应用设计**，没有 PI 正式分析或结果。

| 候选问题 | 可设计的 Topic 证据 | 可画的图 | 需要补充的验证 |
|---|---|---|---|
| Fibroblast 相关成分 | 多个成纤维细胞相关基因组合、参考表达一致性、基质区域定位 | β特征、θ空间图、参考相关 | 独立 scRNA/蛋白/组织验证；区分类型与状态 |
| Endothelial 相关成分 | 内皮特征组合与血管位置一致 | Topic/血管标记位置、多重染色对应 | 血管组织学和参考类型；防止共享炎症基因误注释 |
| ECM 重塑程序 | ECM组织、胶原/基质降解等审查过的基因集 | 条件性富集、排序基因、空间图 | 蛋白与组织形态/功能实验 |
| 炎症相关程序 | 免疫/炎症基因组合，允许多个来源 | Topic图、免疫参考/富集 | 不能仅凭炎症基因给出具体免疫类型 |
| 机械转导相关表达 | 经过物种/ID和方向审查的力学响应基因集 | GSEA/β/空间分布 | 真实力学测量；表达不是力或刚度 |
| Fibroblast–Endothelial 邻域 | 两个有证据的候选成分在定义空间尺度上的关联 | 距离/邻域置换图 | 合理空间零假设、细胞级定位；通讯需独立证据 |
| PI 与 Healthy 差异 | 跨患者可比的 matched Topics 或联合空间 | 以患者为单位的组成/程序图 | 足够患者重复与混杂控制；不能用spot伪重复 |

实际 marker 和 pathway 列表应由当前文献、物种和用户研究框架审查后确定；此处不预先把某个 Topic 命名为 Fibroblast 或 Endothelial，也不硬编码预期 PI 差异。

特别注意三条边界：**机械转导相关表达不等于组织刚度的直接测量；空间邻近不等于真实细胞通讯；Topic 注释不等于证明新的细胞亚群。** 真实 tissue stiffness 需要 AFM/流变等独立方法，细胞通讯需要分辨率、分子和功能证据；本模型不能直接推断命运或基因调控因果。

## 7. 建议的交付状态

新数据开始时记录“仅完成代码/需要真实数据验证”；少量公开或模拟数据验证后记“已用小样本验证”。只有真实数据全流程执行、数值/图件审查和科学结论核查完成后，才标“已完成正式分析”。模拟图必须在图注和文件名清楚标注。正式发布 GitHub 前再次检查隐私、样本标识、原始数据许可、文件大小与本地私人路径。
