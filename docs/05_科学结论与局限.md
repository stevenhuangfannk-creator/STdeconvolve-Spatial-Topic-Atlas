# 科学结论与局限 / Claims and limitations

审查日期：2026-10-19。本页将官方模型能力与本项目下游设计区分；未运行的模块不产生结果。

## 1. 每类证据可以支撑什么

| 观察或输出 | 可以表述 | 不能直接表述 | 下一步验证 |
|---|---|---|---|
| β 中一组基因概率较高 | 某 Topic 的代表性表达特征 | 这些基因在单个真实细胞中全部共表达 | 空间单细胞/单分子或多重染色 |
| θ 在特定区域较高 | 所选模型下 Topic 的相对组成在该区域富集 | 真实细胞绝对数量增加、细胞迁移 | 分割计数、组织学、匹配参考型解卷积 |
| marker 与参考 β 相关 | Topic 与某已知类型/层的表达相似 | 已独立证明类型身份或新亚群 | 多 markers、外部参考、组织验证 |
| GO/GSEA 显著 | 排名或入选基因相对于指定基因集存在富集 | 通路已被实验证明激活或具有因果作用 | 蛋白/功能实验与独立数据 |
| 两个 Topics 邻近或共定位 | 在指定空间统计量及零假设下有关联 | 两种细胞直接通讯 | 更高分辨率定位、配体受体及功能验证 |
| PI 与 Healthy 的组成不同 | 具备生物学重复并控制混杂后可估计条件关联 | spot 数量等于独立样本数，或疾病导致变化 | 以患者/动物为单位统计，独立队列 |
| 机械转导相关基因富集 | 机械响应/ECM 相关表达特征 | 测得组织刚度、受力或弹性模量 | AFM、流变或其他力学测量 |

表中验证建议是本项目的科研设计，不是 STdeconvolve 内置验证功能。模型 θ 是转录本混合模型下的相对权重，不能直接解释为细胞数，也没有校正不同细胞类型的 RNA 含量。[原论文 Methods](https://pmc.ncbi.nlm.nih.gov/articles/PMC9055051/#Sec11)

## 2. LDA 假设与失败信号

官方强调成分比例跨 spots 的异质性和有信息的共表达基因。若所有 spots 都近似相同混合比例，LDA 难以唯一分离成分；若类型仅存在很弱差异或仅形态区别，也可能无法恢复。高 dropout、基因面板不足、spot 太少、批次/深度差异主导表达，都应降低解释强度。[官方 Failure Examples](https://jef.works/STdeconvolve/failure_examples.html)

重点查看 `alpha`、perplexity、rare Topics、β 特征和空间分布。`alpha >= 1` 是未分离出稀疏、不同成分的警示；`alpha < 1` 只满足一种模型形态，不是生物学正确性证明。rare Topic 数量上升可提示过度拆分，但低占比也可能是真实稀有成分，不能自动删除并称其为噪声。论文关于少于约 10 spots 表现下降来自特定模拟实验，不是保证 11 spots 即可靠的通用门槛。[Discussion 与补充 S19–S22](https://pmc.ncbi.nlm.nih.gov/articles/PMC9055051/)

## 3. 预处理与数据尺度

LDA 接受非负整数 counts，不能输入 Seurat `scale.data`、SCT residuals、整合 embedding 或 log-normalized 数值。空间坐标应与 spot ID 一一对应，检查过滤后顺序与坐标单位。模型标准流程不使用邻域先验，因此空间连续图样是结果展示，不能视为算法已显式检验空间显著性。

高测序深度有更多证据，但也可能改变可检出基因、特征选择和组成估计。应检查每 spot 总 counts/检出基因与 θ 的关联，保留不同深度区域，并在有依据时设计深度敏感性分析；不能为了美观筛除不符预期的 spots。跨样本时需一致的输入尺度和审查过的共同基因。[Getting Started](https://jef.works/STdeconvolve/getting_started.html)；[官方源码](https://github.com/JEFworks-Lab/STdeconvolve/blob/13b1953263a5ce34e2471c4defebedbda44c7d08/R/functions.R)

`getBetaTheta(perc.filt=0.05)` 会把低于 5% 的 θ 置零并重新归一化，甚至删除全零 Topic；这可改变后续均值与相关性。本仓库应同时保存未经阈值过滤的 θ 与展示用 θ，统计方法必须注明用了哪一个。β 只覆盖入模基因，不能凭 β 推断未入模基因表达。

## 4. mOB 标签不是细胞类型真值

官方 `mOB$annot` 为五个粗组织层。用同一空间数据按标签汇总得到 layer expression proxy，再与 β 比较，是组织结构一致性检查，不是匹配的 scRNA 细胞类型参考，也不是对 θ 绝对准确度的独立检验。尤其不能把相关矩阵标题改成“真实细胞类型准确率”。[官方 Annotation 教程](https://jef.works/STdeconvolve/celltype_annotation.html)

一个层中存在多个细胞类型，同一类型也可能跨层分布。Topic 与组织层、推断细胞类型、表达程序是三个不同层次的标签。保存原始 Topic ID、候选标签、证据、备选解释和置信度，允许多个 Topics 同属一个类型、单个 Topic 未注释。

## 5. 稳定性与多样本比较

固定随机种子保证可复现的一次运行，不能代替稳定性检查。论文 S7 的独立生物学重复表达匹配是跨样本证据；本项目重复随机种子是数值敏感性检查，二者不能相互替代。比较独立模型须先按 β 的共享基因匹配 Topics，并报告完整相关矩阵、共享基因数量与未匹配对象；强制 Hungarian 配对即使相似性很弱也会给出一对一结果，因此配对本身不等于身份一致。[官方 Combining 教程](https://jef.works/STdeconvolve/combining_datasets.html)

官方建议同组织独立生物学重复可以分别解卷积；同一样本的多切片在共享成分假设合理时可联合建模，并可取各切片 OD genes 的并集。合并不自动消除批次效应。若疾病特异状态是目标，联合模型可能掩盖样本特异程序，分别拟合又会带来匹配与尺度问题，需先明确科学问题。

## 6. 富集与空间统计的边界

本项目扩展 GO/KEGG/Reactome/GSEA 时，至少记录物种、ID 体系、数据库日期/版本、基因排序、背景基因、基因集大小和 BH 等多重检验方法。ORA 的背景应来自可进入检验的基因，而非默认全基因组；β 只含 OD genes 时有预选偏倚。基于 β 的正排序富集不是 case–control 差异 GSEA；负的生物学方向不能从全非负 β 值直接得到。

空间共定位必须定义距离、图结构、统计量和置换单位。简单随机打乱 spots 可能破坏组织分区、空间自相关与测序深度结构，导致不合理零假设；跨样本、跨层或不同坐标单位不能直接拼接计算距离。结果首先称为“指定零假设下的空间关联”，不能升级为通讯或因果。标准 STdeconvolve 不直接实现这些扩展。

## 7. 平台适用性与方法组合

原论文展示 Spatial Transcriptomics、Visium、DBiT-seq 与 Slide-seq 数据；适用前提仍是有足够统计信息的多细胞混合 counts。亚细胞分辨率、极低捕获或稀疏基因面板不能因为名称属于“空间转录组”就假定适用。官方另有 [Visium 教程](https://jef.works/STdeconvolve/visium_10x.html)，具体链接入口可从[官方主页](https://jef.works/STdeconvolve/)导航。

STdeconvolve 与 Cell2location/RCTD/SPOTlight 的相符可增加信心，分歧也有信息价值，但多个方法共享同一 counts 或 marker，并非真正独立验证。没有本项目的公平 benchmark，不应据原论文片段给出通用性能排名。方法比较与一手来源见 [论文精读第 9 节](01_论文精读.md#9-与参考型方法的区别--method-comparison)。

## 8. 建议的论文措辞

建议： “在 K=…、…基因和…预处理条件下，无参考 LDA 分离出…个潜在表达主题。Topic …在…区域相对富集，并与…参考/基因集相似。该结果提示…，仍需…验证。”

避免： “发现新的细胞亚群”“证明细胞通讯”“证实细胞命运转变”“推断真实组织刚度”“揭示基因调控因果”，除非另有足够独立实验支持。

本项目未来 PI 章节只讨论应用设计；目前不使用用户种植体周围炎正式数据，也不产生任何 PI–Healthy 的真实差异结论。
