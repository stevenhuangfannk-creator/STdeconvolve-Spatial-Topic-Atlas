# 常见问题与错误排查 / FAQ and troubleshooting

本文针对本仓库固定版本和官方接口。实际版本查 `environment/sessionInfo.txt`；实际运行查日志与报告，不能根据本 FAQ 判断某步骤已经通过。

## 1. 方法常见问题

**Topic 就是细胞类型吗？** 不是必然。它是 LDA 从共表达模式中拟合的潜在成分，可以与细胞类型、共享状态、混合成分或技术差异相关。先保留 Topic ID，再记录候选标签和证据；少量 markers 不足以宣布新亚群。

**如何选择 K？** 在固定语料上联合看 perplexity、α、平均比例 <5% 的 rare Topics、特征基因、空间图和相邻 K。`optimalModel(opt="min")` 是明确的最小 perplexity 规则，不能保证找到真实类型数；若最小值在搜索末端，说明范围限制。

**为什么不同 K 得到不同结果？** 模型对同一混合数据做不同粒度的分解，可能合并或拆分表达程序，且 Topic 编号会置换。比较时应看匹配 β、θ 和基因特征，不直接对齐编号。不要为了匹配预期亚群无限调 K。

**固定种子是否说明稳定？** 固定种子让一次运行可复现。应多种子拟合、匹配后比较全部 Topic，并查看弱匹配；若部分 Topics 不稳定，应降低命名强度。独立切片/生物学重复是另一层证据。

**Theta 是否代表绝对细胞数量？** θ 是模型相对组成，未校正各类型 RNA 含量，不是细胞计数。显示版 θ 还经过 5% 置零和重标化，应保留 raw θ 做统计。

**Beta 数值表示什么？** `beta_probability.csv` 每 Topic 行和为1；`beta_scaled.csv` 乘以1000。β不是原始 spot counts、单细胞表达矩阵或差异表达 p 值；只包含入模 genes。

**如何命名 Topic，为什么有些无法注释？** 综合多个代表基因、参考表达相关、marker 富集、组织位置与外部证据；保留未匹配和歧义。未注释可能因缺失参考、混合程序、捕获不足或不稳定，也可能值得继续研究，但不能直接称“新细胞类型”。

**必须提供单细胞参考吗？** 拟合不需要。可靠细胞类型命名通常受益于合适参考。mOB 的五层标签只是组织层 proxy，不是每 spot 的真实细胞类型组成。

**能用于 Visium 吗？** 原论文与官方有 Visium 示例，前提是输入合适原始 counts 和有信息的多细胞混合。平台名字不保证每个数据都能分离；极稀疏或亚细胞数据需另评估。[官方 Visium 教程](https://jef.works/STdeconvolve/visium_10x.html)

**可以比较疾病与健康吗？** 可以设计，但必须先建立可比 Topic 空间或匹配关系，以患者/动物作为重复单位，控制批次、解剖部位和深度。两张切片或不同种子不能支持疾病群体差异推断。

**如何避免测序深度造成假象？** 检查总 counts、检出基因、组织区域与 θ 的关系，评估低深度区域和特征选择敏感性。不要对 LDA 输入使用 log/scale 数据；不要为了漂亮空间图按期待结果删除 spots。深度敏感性分析应说明其零假设与局限。

**空间邻近是否说明通讯？机械通路是否说明刚度？** 都不能。邻域统计首先是空间关联；力学相关表达不是实际力学测量，需独立分子/功能与力学实验。

上述方法依据：[Getting Started](https://jef.works/STdeconvolve/getting_started.html)、[Annotation](https://jef.works/STdeconvolve/celltype_annotation.html)、[Failure Examples](https://jef.works/STdeconvolve/failure_examples.html)、[Combining Datasets](https://jef.works/STdeconvolve/combining_datasets.html)，审查日期 2026-10-19。

## 2. 环境与启动错误

| 现象 | 常见原因 | 精准处理 |
|---|---|---|
| 找不到 `00_Start.R` / core.rds | R工作目录不是仓库根；未先跑01 | VS Code 打开仓库并 `setwd()` 到根；按编号运行；检查真实文件存在 |
| 缺少 STdeconvolve 或依赖 | 没有加入项目隔离包库；当前R不同 | 检查 `.libPaths()`、`R.version.string`，阅读安装脚本；不修改全局库来凑环境 |
| package 不可用于当前R | R/Bioconductor/二进制版本不匹配 | 记录版本和原始错误；先确定兼容方案，再决定隔离环境，不盲目升级降级 |
| Windows提示缺编译工具/GSL | 尝试源码安装编译型依赖 | 优先检查与当前R匹配的官方binary；不静默安装整套工具链 |
| 权限/路径失败 | 工作目录不可写、文件被查看器锁定 | 仅调整本项目可写输出路径或关闭该文件；不删除其他项目文件 |
| 内存不足或worker错误 | 全矩阵dense、多核复制或过多K | 停止当前大任务，保留日志，估算资源；默认单核、先筛基因；不自动扩容到大任务 |
| 字体/中文导出异常 | Cairo/ragg/字体可用性不同 | 安装前先核查已装字体；统一font参数；保留可读轴标签，核查三格式 |

## 3. 输入和模型错误

| 错误/信号 | 解释 | 处理与记录 |
|---|---|---|
| `counts must contain integer gene counts` | 输入为连续归一化或错误层 | 取raw counts，不用round强行伪造计数 |
| `Each row (pixel)...non-zero` | gene选择后某spot全零，或矩阵方向错 | 核对fitLDA为spot×gene；保存全零spot清单并审查排除 |
| 预处理得到0或极少基因 | 物种/ID问题、阈值不合适或低质量 | 检查输入/规模；记录调整前后参数，不用随机基因替换 |
| α≥1或Topic几乎均匀 | 信息不足/比例变化不足/特征不区分 | 看官方失败场景、基因选择和数据异质性；不要只增加K |
| 每次种子不同，某Topic变化大 | 局部最优/可辨别性不足 | 固定参数并多种子诊断；报告未稳定成分，避免过强命名 |
| θ有0或某Topic消失 | `perc.filt=0.05`过滤与重标化 | 比较raw与displayθ；不要将显示0当作绝对不存在 |
| K=8没有复现论文K=12 | 本仓库快速教程与论文预处理不同 | 查论文精读的232/255基因、K网格与阈值对照；不能靠改标签消除差异 |

如果为了故障排查临时改单 K 调用，应核查 `fitLDA()` 内部多 K 的 knee 诊断是否适用于单元素。固定 K 的重复拟合可使用同版本官方内部 `topicmodels::LDA()` 调用和相同控制参数，并清楚标为实施调整；不更换算法。

## 4. 注释与绘图错误

**相关热图报 “Discrete value supplied to a continuous scale”**：某些 ggplot2 版本与官方 `correlationPlot()` 对纯数字 Topic 名的处理不兼容。可仅在绘图用矩阵行名添加 `Topic ` 等文字前缀，保留原始模型ID与相关系数。官方注释教程本身也将行名改成 `decon_1` 等字符。不要改数值去消除错误。

**GSEA 输出列名与网页不同**：旧教程示例使用 `p.val/q.val/sscore/edge`；固定版本源码使用 fgsea，查看实际 `names()` 后读取 `pval/padj/ES/NES/leadingEdge`。不要仅因为列名不匹配就改算法。[固定版本源码](https://github.com/JEFworks-Lab/STdeconvolve/blob/13b1953263a5ce34e2471c4defebedbda44c7d08/R/functions.R)

**GSEA没有显著条目**：先看与β基因的交集大小、排序、物种、ID和基因集范围。没有显著性是合法结果，保留全表；不能降阈值直到出现预期通路。组织层 proxy 的显著性也不是独立类型证据。

**相关矩阵有 NA**：可能是共同基因太少、零方差、误用概率阈值或spot对不齐。保存共享ID与NA位置，检查后再匹配；不能把NA默认为0并继续宣称匹配可靠。

**饼图层轮廓难看清**：检查group colors和stroke，提升可读性；不能改 Topic θ 或组织层标签来使图更像原图。不同 Topic 的颜色在不同面板中保持一致。

**空间图翻转/形状不对**：核查坐标轴、阵列/像素/µm单位和图像原点。任何反转/旋转仅为已记录坐标变换，不改原始数据；跨切片不能默认共用坐标系。

## 5. 扩展模块与联网错误

| 现象 | 应做的检查 | 不允许的替代 |
|---|---|---|
| KEGG/Reactome下载失败 | 原始URL、状态、文件大小、ID格式、缓存哈希；记录受阻库 | 换成随机或手工通路结果冒充真实下载 |
| 富集背景很小/无显著结果 | 报告232 OD基因等预选背景及注释覆盖率；方法为条件性探索 | 改用全基因组背景制造显著性 |
| 官方额外mOB数据不可下载 | 确认来源/格式；保存失败日志并报告 | 用同一切片随机拆分当作独立样本 |
| cache参数不匹配 | 比较基因、K、种子、输入哈希；明确重拟合 | 使用过期模型却配新参数表 |
| 近邻统计不显著 | 检查距离单位、图结构、置换次数与假设，保留null分布 | 反复选距离直到显著而不记录选择 |
| 置换p值很小 | 核查是否打破组织层/深度/空间自相关；说明分辨率 `1/(B+1)` | 将关联直接称作细胞通讯 |

缓存源文件的日期是本次读取日期时应注明，不冒充原始下载日期；未来重新运行可基于文件哈希核对确实用了相同内容。

## 6. 报错后向协作者提供什么

提供最小错误信息、失败脚本/步骤、`sessionInfo()`、输入矩阵维度、参数和非敏感ID摘要；不要贴整张私人数据矩阵或个人路径。先局部定位失败，不重新运行全部大分析。修复后执行能复现错误的最小检查及受影响模块，明确其状态是 PASS、PARTIAL、BLOCKED 还是 NOT_RUN。

详细科学边界见 [05_科学结论与局限.md](05_科学结论与局限.md)，新数据应用方案见 [06_真实数据使用指南.md](06_真实数据使用指南.md)。
