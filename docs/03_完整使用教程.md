# 完整使用教程 / Workflow

本教程使用真实官方公开 mOB。目标是理解潜在成分、空间分布与解释边界。先完成 01–04，再执行 05–07。论文参数分支 `01b_Paper_mOB.R` 独立保存，不覆盖快速教程结果。

## 1. 输入与预处理

`mOB$counts` 是 gene × spot 原始整数矩阵；`pos` 是有 spot ID 行名的 x/y；`annot` 是有名字的组织层 factor。01 将原始对象保存到 `data/raw/mOB_official.rds`，并输出 ID 对齐索引。

| 步骤 | 参数 | 本次实际维度 | 为什么做 |
|---|---|---|---|
| 原始输入 | 包内 mOB | 15,928 × 262 | 保留未经本项目改写的官方对象 |
| cleanCounts | min.lib.size=100, min.reads=1, min.detected=1 | 14,828 × 260 | 排除极少计数/检出的基因与低计数 spots |
| restrictCorpus | removeAbove=1, removeBelow=.05, alpha=.05, nTopOD=1000 | 232 × 260 | 选择对区分成分有信息的过度离散基因 |

阈值包含关系以固定源码为准；例如不是“至少 100”，而是实际源码中的严格比较。232 小于上限 1000，因此不会凭空补足 1000 基因。处理前后规模见 `data/processed/preprocessing_summary.csv`。

## 2. K 与模型

01 将语料转为 spot × gene：`fitLDA(t(as.matrix(corpus)), Ks=2:9, seed=0, ncores=1)`。`optimalModel(ldas, opt="min")` 在本次网格选 K=8。不要把“网格内最小”解释成真实细胞类型数已经确定。

02 提供官方 K 图、未阈值化 rare-topic 表及四个种子（0、1、2、3）的固定 K 重复。β Pearson 相似性经过 Hungarian 一对一匹配后再比较；不能直接比较两个模型中的 Topic 1。重复种子用于测量求解器敏感性，同一张切片不是多个生物学重复。

## 3. θ / β

```r
core <- readRDS("data/processed/core.rds")
dim(core$theta_raw) # spot × K
dim(core$beta)      # K × 入模gene
range(rowSums(core$theta_raw))
range(rowSums(core$beta))
```

`theta_raw` 每行和 1，供稳定性、邻域和描述性统计。`theta` 按官方教程将 spot 内 <5% 置零，再重新归一化，仅用于官方饼图显示。`beta` 每行和 1000；`beta_probability.csv` 每行和 1。它不是全转录组的真实测得表达，也不是差异表达检验结果。

## 4. 空间图与 marker

03 使用官方 `vizAllTopics`、`vizTopic`、`vizGeneCounts`。圆饼颜色表示 Topic，轮廓表示组织层；单 Topic 色深表示模型比例。基因图展示真实 counts，测序深度未在图中去除。热图采用每个 Topic top5 β genes 的并集，颜色为 log(1+β×1000)，没有逐基因 z-score。

如果想匹配另一张参考图，优先修改点大小、饼半径、面板数、字体和输出尺寸；不为了相似度改变原始注释或筛掉 spots。

## 5. 组织层代理注释

04 用 `model.matrix(~0+annot)` 生成每层 spot 指示矩阵，再聚合真实 counts，建立层表达代理。`getCorrMtx` 计算表达谱相关和比例相关；`annotateCellTypesGSEA` 对真实层 marker 集进行富集。这遵循官方 vignette，结果是同切片内部的关联演示。

层 marker：聚合 counts >10、相对其他层平均值 log2FC>1、最多 top200；GSEA 按与 β 的交集和 minSize 筛选。全部 Topic 的 `proposed_cell_type` 保留 UNASSIGNED，由研究者结合独立参考与组织学审查。缺少独立 scRNA 时不伪造“注释准确率”。

## 6. 功能与跨样本

05 的 GO/KEGG/Reactome/GSEA 是本项目扩展，以真实数据库交集为背景；不能把全基因组当作一个仅 232 基因模型的可检出背景。注意映射覆盖率、小背景和 pathway 冗余，查看每库状态，不把未显著项称为阳性。

06 从官方 Rep2 来源获取另一真实切片。共享基因上独立拟合、比较 β 并匹配 Topics。两张切片仅作描述，不开展疾病差异或生物重复显著性检验。不要将独立拟合 Topic 编号直接对应。

07 根据原始阵列坐标建空间权重，对 raw θ 进行置换。零假设、置换数量、BH 范围与局限详见 `扩展方法说明.md`。空间梯度、组分闭合性及组织结构都可能影响关联；不能将邻近解释为通讯。

## 7. 输出与复用

主要中间对象保留在本地，GitHub 不上传原始数据库、包库或模型。读取已有 `core.rds` 可跳过 01 的重新拟合，但修改预处理、K 或 seed 后须明确重跑依赖模块，不能混用旧图与新模型。

所有图件应同时有 PNG、PDF、SVG，同名三格式对应同一图对象。最终运行状态见 `FINAL_REPRODUCTION_REPORT.md`；每张图的解释见 `04_图件解读指南.md`。新数据的输入合同和 PI 未来应用见 `06_真实数据使用指南.md`。
