# 安装与环境配置 / Environment

本次使用已经存在的 Windows R 4.6.1，STdeconvolve 1.3.2，Bioconductor 3.23。没有升级或降级 R，没有改写用户原有 Seurat / Bioconductor 包。R 4.3.1 同时存在，但未用于本项目拟合。硬件为约 16 GB 物理内存，默认 `ncores=1`。

## 1. 兼容性先检查

官方固定提交的 `DESCRIPTION` 声明 R >= 4.1；这只是最低语法/依赖要求，不表示任意 R 与任意 Bioconductor 可以混用。官方 GitHub 首页还保留过时的 `BiocManager::install(version='devel')` 示例，本项目没有执行该命令。[固定源码](https://github.com/JEFworks-Lab/STdeconvolve/blob/13b1953263a5ce34e2471c4defebedbda44c7d08/DESCRIPTION)

```r
R.version.string
.libPaths()
if (requireNamespace("BiocManager", quietly = TRUE)) BiocManager::version()
```

不要把 R 4.3 的编译包库强行加入 R 4.6。不要自动安装 Rtools；本次 STdeconvolve 本体是纯 R，两个缺少的计算包使用 Windows 二进制，GO 数据库是源码形式的纯数据包，不需要 C/C++ 编译。

## 2. 独立包库与安装

在 VS Code 打开本仓库，终端工作目录设为仓库根目录。选用已经审查过的 R 解释器。以下 PowerShell 命令中的 Rscript 路径请按自己机器修改：

```powershell
& 'C:/Program Files/R/R-4.6.1/bin/x64/Rscript.exe' --vanilla environment/install_dependencies.R
```

安装脚本只在主动调用时运行。`00_Start.R` 只检查依赖，不会自动安装。独立目录是 `environment/R-library/`，由 Git 忽略；仍允许读取所选 R 版本中已存在的兼容包。

本次新增到独立库：STdeconvolve、topicmodels、fgsea、NLP、tm、fastmatch、org.Mm.eg.db、GO.db。其余使用已有兼容包。全部已安装版本在 `environment/installed_packages.csv`，实际载入环境在 `environment/sessionInfo.txt`。

STdeconvolve 固定在官方 `package` 分支的提交 `13b1953263a5ce34e2471c4defebedbda44c7d08`。官网不同分支可能显示其他版本，不能把本次 1.3.2 写成“最新版本”。包依赖快照记录了本次状态，但安装脚本对其他依赖仍使用仓库当前可得版本；将来严格重演时需要逐项恢复版本，并检查二进制可得性，不能保证未来安装完全一致。

## 4. 运行与内存

```r
setwd("你的仓库根目录")
source("00_Start.R")
source("01_Official_Reproduction.R")
source("02_Topic_Number_Selection.R")
source("03_Spatial_Visualization.R")
source("04_Topic_Annotation.R")
```

后续模块从已保存对象继续，不重新执行上游 LDA 网格。每个脚本的文件头说明输入输出；VS Code R Interactive 会预览，同时导出正式三格式图件。

推荐 Windows 串行运行器：

```powershell
./environment/run_pipeline.ps1 -Rscript 'C:/Program Files/R/R-4.6.1/bin/x64/Rscript.exe'
```

运行器记录 `environment/process_metrics.csv`；R 内记录 `run_metrics.csv`。两种内存指标必须分开读：R 堆内存高水位不是系统 RSS；进程表记录的是采样到的 R 父进程工作集，不包含其他应用和子进程。本次最早 01/02 使用 `bin/Rscript.exe` 启动包装器，其约 7 MB 数据只反映包装器，不能当作模型真实内存；对应 R 堆内存及之后 x64 直接进程记录另列。未测得整机峰值，不能宣称完整峰值小于该数。

## 5. 已遇到的普通问题

- Git HTTPS clone 曾被连接重置；使用官方 codeload ZIP 获取同一源码，记录固定提交。没有换算法或数据。
- 环境继承的 `LC_*=C.UTF-8` 在 Windows R 启动时产生 locale warnings。模型可正常执行；不为消除此警告修改系统区域设置。
- `correlationPlot(annotation=TRUE)` 对纯数字 Topic 行名在 ggplot2 中发生离散/连续尺度冲突。只在绘图矩阵副本加 `Topic ` 前缀；相关系数与原始矩阵不变。
- mOB 原始 counts 和 pos 的排序不同，annot 仅覆盖过滤后的 260 spots。始终按现有 ID 匹配，不按行位置重命名。

如果需要升级/降级 R、大量改动依赖、换数据或预计超过 16 GB，请停止并先作环境方案审查。
